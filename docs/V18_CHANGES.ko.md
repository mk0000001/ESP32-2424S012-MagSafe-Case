# V17 → V18

실물 피드백: 배터리가 안에서 흔들리고, USB-C는 맞지만 구멍 너머로 기판이 많이 보임.

| 항목 | V17 | V18 |
|---|---|---|
| 배터리 받침 패드 | 기준 높이 | 0.5mm 높임 |
| 배터리 위아래 자유 이동 | 0.8mm | 0.3mm |
| 가이드 안쪽 | 51×31mm | 50.6×30.6mm |
| 가이드 전체 높이 | 1.9mm | 3.2mm |
| USB-C 뒤 가림벽 | 없음 | 두께1.2mm |
| 가림벽 통과 창 | 해당 없음 | 10.6×5.2mm |
| 바깥 케이블 머리 공간 | 17×10.7mm | 유지 |
| 보드 받침틀·링·바깥 뚜껑·툴 | V17 | 같은 형상 |

가림벽은 추정 USB 소켓 앞면보다 0.6mm 뒤에 놓였다. 아래 끝은 보드 고정 링 앞면과 0.4mm 띄워 회전 공간을 유지한다. 창 가장자리에는 소켓 설명용 외형 기준 각 방향0.6mm 여유를 두었다. 커넥터 바로 둘레의 조립 여유는 남으며 방수/방진 밀폐 구조는 아니다.

고정 링 위치와 화면·PCB 간격3.7mm는 유지한다. 본체 외경65.30mm, 높이26.85mm도 유지한다. 자석 홈과 두 뚜껑의 잠금 방식은 유지한다.

현재 배터리 기준은 사용자 실측50×30×5mm이다. 높인 돌기는 배터리를 눌러 죄는 용도가 아니다. CAD에서0.3mm 자유 이동과0.4mm 이동 시 받침 접촉을 확인했다.
