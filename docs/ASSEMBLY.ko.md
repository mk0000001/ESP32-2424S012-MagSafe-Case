# V18 조립 방법

[영상 MP4](../media/V18/assembly.mp4) · [반복 GIF](../media/V18/assembly.gif)

1. **본체에 보드를 앉힌다.** 화면이 아래, 노란 PCB가 위로 향하도록 놓고 USB-C를 본체 충전 구멍에 맞춘다.
2. **보드 받침틀을 넣는다.** `BOARD_SUPPORT_FRAME_V18_PRINT.stl`의 홈 3개를 본체 돌기 3개에 맞춘다.
3. **보드 고정 링을 잠근다.** `SCREW_RETAINING_RING_3POINT_V18_PRINT.stl`을 손으로 나사산에 먼저 맞춘다. 툴의 짧은 돌기 3개를 링 홈에 끼우고, 기기 뒤에서 보아 시계 방향으로 닿아 멈추는 곳까지만 조인다. 툴은 빼낸다.
4. **자석을 붙인다.** 안쪽 배터리 받침판의 평평한 아래쪽 면에 붙인다. 흡착 면은 보라색 바깥 뚜껑 쪽을 향한다. 접착 전에 실제 자석이 홈에 들어가는지 확인한다.
5. **안쪽 받침판을 잠근다.** 바깥 뚜껑의 안쪽을 위로 놓는다. 받침판의 큰 구멍 2개로 기둥 머리 2개를 통과시키고, **뚜껑 안쪽에서 보아 시계 방향 10°** 돌려 좁은 홈에 걸어 잠근다. 큰 구멍에 기둥 머리를 억지로 눌러 끼우는 스냅 구조가 아니다.
6. **배터리를 놓고 연결한다.** 50×30×5mm 배터리를 50.6×30.6mm 가이드 안에 놓는다. 전선을 안쪽으로 정리한 다음 보드 배터리 커넥터에 연결한다. 배터리를 눌러 찌그러뜨리며 닫지 않는다.
7. **뚜껑 전체를 잠근다.** 넓은 돌기 1개와 본체의 넓은 진입 홈을 맞춰 넣고, **기기 뒤에서 보아 시계 방향 20°** 돌려 멈추는 곳까지 잠근다.

## 열 때

- 뚜껑 전체: 기기 뒤에서 보아 반시계 방향 20°.
- 안쪽 받침판: 분리한 뚜껑 안쪽에서 보아 반시계 방향 10°.
- 보드 링을 풀기 전에는 뚜껑과 배터리를 꺼내고 배터리 커넥터를 분리한다.

안쪽 받침판과 바깥 뚜껑은 **바라보는 면이 서로 반대**다. 여기서 적은 방향은 각 단계에 명시한 면에서 본 방향이다. V17 초기 안내의 안쪽 판 '반시계 잠금' 표기는 정정했다.
