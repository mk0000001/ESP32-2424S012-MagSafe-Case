# 사용자 제공 ESP32 모듈

원본 파일:`1.28inch_ESP32-2424S012.zip` / 118,417,978 bytes / ZIP내 항목2,746개.

사용자가 준 원본을 변경하지 않고NAS의`vendor-original/`과 [V18 Release](https://github.com/mk0000001/ESP32-2424S012-MagSafe-Case/releases/tag/v18)에 보존했다. 예제·라이브러리·플래시 도구는 전체 원본ZIP에 들어 있다. 실행 파일은 보관만 했으며 이 작업에서 실행하거나 기판에 펌웨어를 쓰지 않았다.

## 바로 볼 자료

`vendor/` 안에 다음 원본 항목을 경로 그대로 추출했다.

- `2-Specification/`:ESP32-2424S012 영문 사양서.
- `3-Structure_Diagram/`:구조도 이미지2개.
- `4-Driver_IC_Data_Sheet/`:ESP32-C3-MINI-1 데이터시트.
- `5-Schematic/`:보드 회로도와ESP32-C3-MINI-1U 이미지.
- `6-User_Manual/`:1.28인치 모듈 시작 안내.

실물 PCB 사진:[pcb-user.jpg](photos/pcb-user.jpg). 사진에서`HW-791`, `ESP32-2424S012`, `V0.0.1`, `ESP32-C3-MINI-1U`를 확인할 수 있다.

제조사 사양서의 크기는38.5×37mm, 유효 화면 지름32.4mm, 전원5V, 약100mA이다. 원문은N(비터치)/C(정전식 터치) 변형을 함께 다룬다. 사용자 제공 상품명은 정전식 터치형이지만 사진 속PCB에는 전체 변형 접미사가 표시되지 않는다.

이 자료 묶음에서 전체 모듈 STEP/STP/IGES는 발견되지 않았다. 케이스CAD와 조립 영상의 보드 외형은 도면·사진·사용자 실측으로 만든 **설명용 참고 형상**이다.
